# Fonts

third party. All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org):

Archivo (Omnibus-Type) · Inter (Rasmus Andersson) · JetBrains Mono (JetBrains) · Fraunces (Undercase Type) ·
Caveat (Impallari Type) · Press Start 2P (CodeMan38). Latin subset, woff2. Declared in `assets/css/fonts.css`.
